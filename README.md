# KU-BD-Fish

**High-Resolution White-Background and Segmented Images for Species Classification**

[![DOI](https://img.shields.io/badge/DOI-10.17632%2Fn9m5bywxwc.3-1f4fd1?style=flat-square)](https://doi.org/10.17632/n9m5bywxwc.3)
[![Mendeley Data](https://img.shields.io/badge/Download-Mendeley%20Data-22a565?style=flat-square)](https://data.mendeley.com/datasets/n9m5bywxwc/3)
[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-0f1729?style=flat-square)](https://creativecommons.org/licenses/by/4.0/)

KU-BD-Fish is an image dataset of **26 freshwater fish species native to Bangladesh**, built at **Khulna University** for fish species classification and related computer-vision research.

## At a glance

| | |
|---|---|
| **Images** | 940 high-resolution images |
| **Species** | 26 freshwater fish species native to Bangladesh |
| **Versions per image** | Raw photo + segmented image (background removed) |
| **Capture** | One fish per image, white background, controlled lighting |
| **Devices** | iPhone 14 Plus, Samsung S23 Plus |
| **Organization** | One folder per species, plus a metadata file with species names and details |
| **Version** | 3 (October 2025) |
| **License** | CC BY 4.0 |

## Get the dataset

The images are hosted on Mendeley Data:

**→ [data.mendeley.com/datasets/n9m5bywxwc/3](https://data.mendeley.com/datasets/n9m5bywxwc/3)**

## Intended uses

- Fish species **classification**
- **Segmentation** and **object detection**
- Morphological analysis
- Taxonomic and biodiversity research
- Teaching computer vision and machine learning
